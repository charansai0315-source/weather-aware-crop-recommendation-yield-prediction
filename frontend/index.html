    WHERE THE DATA COMES FROM

    Each detail has
    a clear source.

    01

    Weather API

    Temperature, humidity, wind and the next 7 days of rainfall are looked up from the location you enter.

    02

    Your soil report

    You type in the soil texture, NPK and pH values. Moisture is optional and only included if you have a reading.

    03

    Python machine-learning model

    A Random Forest ranks crops from NPK, pH, temperature and humidity using a public crop dataset. Season, soil texture and the seven-day rain total are not model inputs.

    04

    Historical yield data

    When state, crop and season records match, yield is estimated from district production history through 2015. It is a historical benchmark, not a current-season or field-specific prediction.
